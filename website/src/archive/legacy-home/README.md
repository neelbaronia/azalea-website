# Archived Listen/Create homepage

This directory preserves the homepage entry point that was live through commit
`bb14f71`. Its `Navbar`, `ConsumerView`, `PublisherView`, and supporting assets
remain in `src/components` and `public`, so the experience can be restored by
moving `HomePage.tsx` back to `src/app/page.tsx`.

The archive is intentionally not routed and is not part of the public site.
